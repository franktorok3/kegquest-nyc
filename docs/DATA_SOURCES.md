# Source and coverage policy

The NYC Brewers Guild directory at https://www.nycbrewed.com/breweries supplies discovery candidates; official brewery location pages supply published details. `src/data/seeds.json` is a reviewed exact-URL allowlist. `browser-sources.json` adds reviewed crawl URLs, and `browser-review.json` maps literal address, hours and amenity evidence to published fields. Raw rendered evidence stays in ignored `work/browser-evidence`; factual menu fixtures exercise adapters in tests. `location-meta.json` contains reviewed weekly schedules, visit status, nullable amenities and supplemental address evidence. `geocodes.json` records US Census geocoder URL, match, timestamp and street-interpolation precision.

A directory listing is not a verified walk-in taproom. Candidates missing verified addresses remain outside the location browser. The source snapshot includes failures for diagnostics. Closed, event-only and retail classifications are explicit. Food, outdoor seating, accessibility and other amenities stay unknown unless evidence is recorded. An empty verified-amenity result is preferable to a fabricated amenity.

The initial supported tap adapters parse Other Half's explicitly labeled draft panels and Eckhart's On Draft Now section. Required source fields are retained. Cans/bottles, store catalogues and unrelated products are excluded. JSON-LD and HTML-table helper parsers are available for opt-in tested adapters, not indiscriminate extraction. Playwright Chromium now renders reviewed JavaScript pages after robots-aware preflight. Tested adapters also extract location-specific menus for Evil Twin, Grimm, Fifth Hammer, Flagship, Kills Boro, Gun Hill and the official-linked Threes BeerMenus page. Only explicit draft/cask offerings are included. PDF/image/OCR menus remain unsupported. Unsupported or blocked menus display unavailable.

Every attempt records URL and checkedAt; verifiedAt is the last successful detail fetch and menuVerifiedAt is the last successful menu extraction. Fresh means within 24 hours, recently checked within 72 hours, stale beyond 72 hours. Failed refreshes preserve the previous menu for history but exclude it from current search and recommendations. Old data does not regain freshness merely because an attempt ran. Successful page fetch alone does not validate every field.

The crawler checks robots.txt, fails closed on inaccessible robots policies, honors crawl-delay within its bounded budget, paces hosts, uses a named user agent, limits attempts/time/content size, blocks private DNS destinations and rejects unreviewed redirects. Transient server/network failures receive exponential backoff; 429 is not immediately retried. ETag/Last-Modified caching avoids retransmitting unchanged local pages. It does not bypass login, CAPTCHA or robots exclusions.

Official-site Open Graph images are remote previews and may be venue photos, logos or product shots. They remain owned/hosted by their publishers, link to the source, and fall back to a typographic placeholder on failure. No invented venue photographs are used. Map data © OpenStreetMap contributors. Before commercial expansion, review image permissions and choose a production tile provider with appropriate capacity.

## New beer drops

The homepage feed uses `src/data/beer-drops.json`, a durable first-observation ledger updated after browser ingestion by `npm run ingest:drops`. Initial history was reconstructed from committed verified menu snapshots. First coverage is labeled **New to guide**; a previously unseen beer on a later comparable source/parser snapshot is **New on menu**. These are discovery dates, never inferred brewery release dates. Names are normalized for whitespace and case; style/price corrections, repeat crawls, failures, and returning beers do not reset first-spotted dates. A new source or parser establishes a baseline for additional coverage. Only beers still present at visitable locations with a successful menu check within 72 hours and first spotted within 14 days qualify. The homepage shows up to six cards with venue diversity, links to the venue and exact source, and an honest empty state. GitHub refresh commits this ledger alongside each catalog snapshot.
